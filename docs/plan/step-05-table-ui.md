# Step 05：牌桌 UI 与出牌交互

## 目标

实现牌桌场景，玩家可以看到四家牌局并进行出牌操作，走通 PLAYING 阶段的完整交互。

## 前置

step 02 完成。必读：`docs/progress/step-02.md`（action 接口）、architecture.md §界面与素材。

## 任务

1. `ui/table/table.tscn` + `table.gd`：牌桌布局——玩家手牌在下方（扇形或横排，可选中多张），对家/上下家手牌以背面或数量显示，中央出牌区显示本轮四家出的牌，角落显示各方已得分数与底牌数。
2. `ui/card_view.gd`：单张牌的可视化，代码绘制（圆角矩形底 + 花色 + 数字，主牌高亮边框），支持选中/悬停状态。
3. 出牌交互：点选手牌 → 点"出牌"按钮；按钮可用性由 `get_available_actions` 驱动；非法选择即时提示（如张数不符、必须跟同花色）。
4. AI 回合：调用 step 04 的 AI（若 step 04 未完成，用"出第一个合法动作"的占位 AI 代替，并在 progress 记录注明），带 0.5~1 秒思考延时。
5. 简单动画：发牌（约 1 秒 2 张）、出牌位移到中央、收分提示。
6. 本 step 只做 PLAYING 阶段的人机交互闭环；亮主/进贡/扣底 UI 在 step 06 做，本阶段用自动策略跳过（直接调 core 接口完成）。

## 产出文件

`ui/table/`、`ui/card_view.gd`（及必要的临时主场景）

## 验收标准

- 在编辑器中运行可以从发牌打到一局结束，玩家全程用鼠标完成出牌，非法出牌被拒绝。
- 规则判断零落在 UI 层：所有合法性都来自 core 接口。
